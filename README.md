# 돈마마 테이블 웹앱

앱 설치 없이 메뉴와 네이버 리뷰 혜택을 안내하는 반응형 웹앱입니다.

- `/`: 첫 화면
- `/menu`: 메뉴 18개, 메뉴 분류, 큰 글씨, 원산지 안내
- `/review`: 직원에게 영수증 요청 → 네이버 후기 작성 → 직원에게 작성 화면 제시
- `/sticker`: 90 × 120 mm 스티커, QR 주소 변경, 글꼴 포함 SVG 다운로드, 인쇄

## 실행

Node.js 22.13 이상이 필요합니다. Windows에서는 `D:\GitHub\권집사님` 경로를 일관되게 사용합니다.

```sh
npm install
npm run dev
npm run build
```

## 내용 수정

`lib/restaurant.ts`에 메뉴명·가격·중량·원산지·리뷰 이동 주소·사이트 주소를 모았습니다. 메뉴와 반 인분 혜택은 제공받은 메뉴판·이벤트 사진을 기준으로 옮겼으며 실제 운영 전 매장에서 확인합니다. 생오겹목살은 원본의 단일 표기를 유지했습니다. 주류 정보가 제공되지 않아 주류 항목은 추가하지 않았습니다.

리뷰 버튼은 사용자가 제공한 장소 ID 18363630의 네이버 모바일 방문자리뷰 페이지로 연결됩니다. 모바일 페이지에서 돈마마 매장명을 확인했습니다. 네이버 페이지의 리뷰 쓰기에서 인증을 진행합니다. 영수증은 사용자의 운영 안내대로 직원에게 요청하는 흐름입니다. 이 웹앱은 리뷰 인증이나 서비스 지급 여부를 자동 판정하지 않습니다.

현재 Sites 접근은 검토용 비공개입니다. 손님이 로그인 없이 사용할 수 있는 공개 주소가 확정되면 `siteUrl`을 바꾸고 스티커 QR도 새로 생성해야 합니다. `/sticker`에서도 주소를 바꿔 SVG를 저장할 수 있습니다. 인쇄 전 실제 크기에서 QR 인식을 확인합니다.

## 인쇄물

`lib/sticker.ts`가 편집 가능한 SVG 원본을 생성합니다. SVG에 공개 라이선스 Noto Sans KR 고딕체을 포함해 다른 컴퓨터에서의 글꼴 변경을 줄였습니다.

```sh
node scripts/export-sticker.mjs
python scripts/export-sticker-pdf.py
```

PDF 생성에는 reportlab과 pypdf가 필요합니다. PDF는 90 × 120 mm, 한 페이지, 벡터 QR과 내장 한글 글꼴로 구성됩니다. 화면에서 주소를 변경해 내려받은 SVG와 배포 시 생성한 정적 PDF는 구분해야 합니다. 주소 변경 후 PDF를 받으려면 화면의 인쇄/PDF 저장 기능을 사용하거나 위 명령으로 다시 생성하세요.

## 자료

스마트폰의 한 열 화면을 기준으로 설계했습니다. 사용자의 피드백에 따라 PC용 옆 사진을 제거하고 고딕체의 굵기·크기·간격을 통일했습니다. 제공 사진의 음식 구성을 참고해 내장 이미지 생성 도구로 만든 음식 사진 2장을 모바일 첫 화면 하단과 해당 메뉴 분류에 작게 배치했습니다. 원본 대신 최적화된 WebP를 사용하며 연출 이미지임을 표시합니다. 실제 운영 전 최종 가격과 이벤트 조건을 매장에서 확인합니다. 글꼴 라이선스는 `public/fonts/OFL-NotoSansKR.txt`에 있습니다.

검증: 프로덕션 빌드, TypeScript, 직접 작성한 코드의 정적 검사, 모든 경로 HTTP 응답, PDF 크기·글꼴·문구 검사, 출력물 QR 디코딩. 기본 제공 UI 컴포넌트 일부는 전체 lint에서 기존 경고/오류가 있으므로 수정하지 않고 작성 코드 검사와 구분합니다.
